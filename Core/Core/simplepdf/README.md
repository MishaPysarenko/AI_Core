# SimplePDF

Небольшая личная C++17-библиотека для типовых операций с PDF.

- MuPDF читает PDF, извлекает и ищет текст, рендерит исходные страницы.
- Cairo создаёт итоговый PDF и рисует векторный текст, линии, таблицы и графики.
- Публичный заголовок не включает заголовки MuPDF/Cairo: детали спрятаны через PImpl.

## Возможности

- открыть PDF и узнать число/размер страниц;
- извлечь текст страницы в UTF-8;
- найти координаты текста;
- визуально заменить существующий текст;
- создать новый PDF и добавить/удалить страницы;
- добавить текст, линии, прямоугольники и изображения;
- нарисовать таблицу, линейный или столбчатый график;
- сохранить результат в новый PDF.

## Важное ограничение

При сохранении каждая исходная страница рендерится MuPDF в изображение, после
чего Cairo накладывает изменения. Поэтому исходный текстовый слой и векторная
графика становятся растровым фоном. Добавленный через SimplePDF текст остаётся
векторным. Качество фона задаётся параметром `rasterDpi` метода `save()`.

Замена текста работает визуально: найденная область закрывается цветом
`coverColor`, затем поверх рисуется новая строка. По умолчанию цвет белый. Если
у текста цветной или сложный фон, передайте подходящий цвет либо перерисуйте
область вручную.

## Установка зависимостей

В каталоге проекта уже находится `vcpkg.json`. Достаточно актуальной версии
vcpkg и выбранного triplet:

```bat
cmake -S . -B build -G Ninja ^
  -DCMAKE_TOOLCHAIN_FILE=C:/Users/Mike/vcpkg/scripts/buildsystems/vcpkg.cmake ^
  -DVCPKG_TARGET_TRIPLET=x64-windows

cmake --build build
```

Для MinGW UCRT:

```bat
cmake -S . -B build-mingw -G Ninja ^
  -DCMAKE_TOOLCHAIN_FILE=C:/Users/Mike/vcpkg/scripts/buildsystems/vcpkg.cmake ^
  -DVCPKG_TARGET_TRIPLET=x64-mingw-dynamic ^
  -DCMAKE_C_COMPILER=C:/msys64/ucrt64/bin/gcc.exe ^
  -DCMAKE_CXX_COMPILER=C:/msys64/ucrt64/bin/g++.exe

cmake --build build-mingw
```

Сначала обновите старый vcpkg, если он сообщает, что schema version 2 не
поддерживается.

## Минимальный пример

```cpp
#include <simplepdf/Document.hpp>

int main() {
    simplepdf::Document pdf("input.pdf");

    pdf.replaceText(0, "Старый текст", "Новый текст",
                    {"Arial", 12.0, simplepdf::Color::black()});

    pdf.addTable(0,
                 {{"Имя", "Значение"}, {"Температура", "24 C"}},
                 {50.0, 300.0, 300.0, 80.0});

    pdf.addLineChart(0, {1.0, 3.0, 2.0, 6.0, 5.0},
                     {50.0, 420.0, 350.0, 180.0});

    pdf.save("output.pdf", 144.0);
}
```

Координаты и размеры задаются в PDF points: 72 points = 1 дюйм. Начало
координат — левый верхний угол страницы. Параметр `y` у `addText()` означает
верх строки, а не базовую линию шрифта.

Изображения PNG загружаются напрямую через Cairo. JPEG и другие форматы,
которые понимает MuPDF, автоматически конвертируются во временный PNG.

Сохраняйте результат под другим именем, чем открытый входной PDF. Это защищает
исходный файл и позволяет MuPDF продолжать читать его во время пересборки.

## Лицензии зависимостей

MuPDF распространяется по AGPL-3.0 либо по коммерческой лицензии Artifex.
Если программа закрытая и будет распространяться, проверьте требования AGPL
или приобретите коммерческую лицензию. Cairo имеет более разрешительные
условия, но итоговые требования определяются всеми зависимостями проекта.
